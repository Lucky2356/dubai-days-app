# Dubai Days — самостоятельный сайт на GitHub Pages

Это **только безопасная оболочка путеводителя**. Личный маршрут, бронирования,
точные даты, бюджет и другие данные поездки не включены в репозиторий.

## Запуск на своём GitHub

1. Создайте **новый публичный** репозиторий, например `dubai-days-app`, в
   своём аккаунте. **Не открывайте** старый `Lucky2356/dubai`: в его истории
   остались личные данные.
2. Загрузите содержимое этого пакета в корень нового репозитория, сохранив
   структуру папок `public/` и `.github/workflows/`.
   Для загрузки из локального Git-клона используйте обычный `git add`, `git commit`, `git push`.
3. В GitHub откройте **Settings → Pages → Build and deployment → Source** и
   выберите **GitHub Actions**.
4. На вкладке **Actions** найдите `Publish Dubai Days` и выберите **Run workflow**
   (либо просто сделайте следующий push в `main`).
5. Дождитесь успешного запуска: ссылка появится в разделе **Settings → Pages**.
   Для репозитория `dubai-days-app` ссылка обычно имеет вид
   `https://Lucky2356.github.io/dubai-days-app/`.
6. Откройте сайт по HTTPS, импортируйте **отдельный личный JSON-файл** и
   установите пароль длиной не менее 12 символов.

## Как обновлять

Редактируйте код в `public/`, затем отправляйте изменения в ветку `main`.
GitHub Actions автоматически публикует новую версию. Никакое обращение к
ChatGPT для этого не требуется.

## Защита данных

- В GitHub можно хранить только файлы из этого публичного пакета. Никогда не
  загружайте личный JSON, резервные копии маршрута или старый исходный код.
- Скрипт публикации отклонит JSON-файлы в папке `public`, а на GitHub Pages
  отправит только содержимое `public/`.
- Импортированный маршрут шифруется браузером и хранится **на конкретном
  устройстве и для конкретного адреса сайта**, не на GitHub.
- На другом телефоне/ПК понадобится повторный импорт. Это не синхронизация.
- Сохраните личный JSON отдельно. После очистки данных браузера или потери
  пароля зашифрованная локальная копия не восстановится без нового импорта.
- Изменение адреса сайта (включая перенос с ChatGPT Sites на GitHub Pages)
  создаёт новое отдельное браузерное хранилище; импорт потребуется заново.

## Структура

- `public/` — только публичные файлы сайта.
- `.github/workflows/pages.yml` — автоматическая проверка и публикация.
- `.gitignore` — защита от случайного добавления частного JSON.

GitHub Pages на тарифе GitHub Free требует **публичный** репозиторий.
Поэтому публичной должна быть только оболочка сайта, а не личная информация.
