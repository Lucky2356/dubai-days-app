# Dubai Days — контроль качества

Все изменения проходят `node --check` для публичных JS-файлов и восемь наборов тестов в GitHub Actions перед публикацией Pages.

## Автоматически проверяется

- PWA: первоначальная установка, ожидание ручного обновления, очистка предыдущего кеша, выдача файла из кеша при сбое сети, отказ кешировать перенаправление на страницу входа, ожидание записи файла в кеш.
- Защита данных: цикл AES-GCM/PBKDF2, отсутствие открытого текста в зашифрованной записи, разные IV, отказ при неверном пароле и изменении шифротекста.
- Обновление маршрута: перенос отметок и текущего этапа при перестановке двух этапов; отказ от несовместимого изменения маршрута.
- Интеграционные сценарии на синтетических данных: сохранение и повторное открытие AES-GCM-записи через имитацию IndexedDB, сохранение последней копии при ошибке записи, корректность PNG-иконок PWA, проверка восьмидневного маршрута и отклонение небезопасного HTML или неполного пакета.
- Независимая проверка скачанной резервной копии: корректный файл, неверный пароль, отсутствие обязательных данных.
- Обновление PWA: запрет перезагрузки без подтверждения, ожидание успешного сохранения, блокировка обновления при сбое записи.
- Структура UI: уникальность идентификаторов, наличие полей, доступных подписей, режимов мобильной вёрстки и соответствие версии ресурсов офлайн-кешу.
- Предварительная проверка пользовательского JSON до ввода пароля: количество дней и этапов; подтверждение доверенного источника исполняемого пакета.
- Полный синтетический жизненный цикл обработчиков: импорт, сохранение, повторное открытие, восстановление с билетом и ошибка записи без замены прежней записи.
- Защищённый мост с iframe: сохранение/чтение/удаление PDF, проверка источника и токена, лимиты вложений, откат изменения в памяти при ошибке сохранения.
- Сборка приватной страницы: удаление сетевых ресурсов, встраивание локальных данных и адаптеров билетов, безопасное экранирование содержимого и мобильная читаемость старого пакета v48.
- Первый вход: проверка доступности подсказок пароля и выбора файла перетаскиванием без обхода предварительной проверки JSON и подтверждения доверенного источника.
- Публикация: GitHub Actions запрещает JSON-файлы маршрута в `public`, проверяет синтаксис и публикует только `public/`.

Запуск локально:

```bash
node --check public/vault.js
node --check public/vault-crypto.js
node --check public/vault-pwa.js
node --check public/sw.js
node tests/pwa-update.test.mjs
node tests/vault-integrity.test.mjs
node tests/integration.test.mjs
node tests/update-flow.test.mjs
node tests/ui-contract.test.mjs
node tests/lifecycle.test.mjs
node tests/bridge.test.mjs
node tests/render-pipeline.test.mjs
```

## Не подтверждено автоматическими тестами

- Реальная реализация IndexedDB и установка PWA на Android/iOS: в тестах использовано имитационное хранилище.
- Функциональный прогон браузера на нескольких размерах экрана и аудит со скринридером: автоматические проверки HTML/CSS не подтверждают реальное поведение интерфейса.
- Полный жизненный цикл пользовательского импорта, восстановления больших PDF/QR-билетов и скачивания резервной копии в Safari. Проверка копии тестируется на синтетическом файле, не на пользовательских данных.
- Работа через официальный домен GitHub Pages без сети после предыдущей авторизации, а также геолокация и внешние карты.
- Актуальность внешних маршрутов, расписаний, тарифов и ссылок на перевозчиков.

Эти пункты следует считать открытыми рисками, а не пройденными проверками. Никогда не очищайте локальное хранилище устройства без защищённой резервной копии.
